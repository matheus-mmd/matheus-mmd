<details>
<summary><b>▸ Como a cobrinha é gerada</b></summary>

<br />

O workflow [`.github/workflows/snake.yml`](./.github/workflows/snake.yml) usa a action
[`Platane/snk`](https://github.com/Platane/snk) para ler o gráfico público de contribuições
de `matheus-mmd` e desenhar a animação. Ele roda **todo dia às 03:00 UTC**, a cada push na
branch padrão e também sob demanda.

**Passo a passo**

1. O arquivo já está versionado neste repositório em `.github/workflows/snake.yml`.
2. Em **Settings → Actions → General → Workflow permissions**, marque **Read and write permissions**.
3. Vá em **Actions → Generate Snake Animation → Run workflow** para gerar a primeira vez.
4. O job publica `snake-dark.svg` e `snake-light.svg` na branch órfã **`output`**.
5. O README consome os arquivos direto do `raw.githubusercontent.com`, no bloco `<picture>` acima,
   trocando automaticamente entre tema claro e escuro do GitHub.

Enquanto o workflow não rodar pela primeira vez, a imagem aparece quebrada — isso é esperado.
